# @vibefork.me/tokens

Design tokens for Vibefork.

## Contents

- `tokens.css` — Tailwind CSS v4 `@theme` block for utility styles.
- `tokens.json` — Token source definitions in JSON format.

## Usage

### CSS

```css
@import "@vibefork.me/tokens/tokens.css";
```

### JSON

```javascript
import tokens from "@vibefork.me/tokens/tokens.json";
```
