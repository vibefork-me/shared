# Vibefork Shared

Shared packages for Vibefork.

## Packages

| Package | Version | Description |
|---|---|---|
| [`@vibefork.me/tokens`](packages/tokens) | `0.0.0` | Design tokens for Vibefork web applications. |
| [`@vibefork.me/i18n`](packages/i18n) | `0.0.0` | Languages and product glossary of every Vibefork product. |

## Check

`npm run check` runs the check of every package that has one. CI runs it on every pull request and on
`main`.
